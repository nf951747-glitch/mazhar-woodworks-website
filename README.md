# Mazhar Woodworks Website

A modern, responsive woodworking business website built using HTML, CSS, and JavaScript. The website showcases custom woodworking services, project galleries, company information, and a contact page with a clean and professional user interface.

---

## Features

- Responsive design
- Modern UI with animations
- Multi-page website
- Interactive gallery with category filters
- Lightbox image preview
- Smooth scrolling
- Loading animation
- Mobile-friendly navigation
- Contact page
- Professional footer

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

---

## Pages

- Home
- About
- Services

- Contact
